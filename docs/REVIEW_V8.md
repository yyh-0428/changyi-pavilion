## 检查的实际边界

本轮使用源码审查、自动化测试、标准模型校验与离线模型渲染。未完成真实浏览器的点击和动画验收，也未在原生 macOS 上双击启动或实测手机帧率；启动器测试验证的是脚本逻辑。阴影范围通过数值投影检查，尚无浏览器阴影实拍。

离线预览不复现网页的实时水面、天空、雾、反射折射、阴影及 ACES 色调映射，因此不能用预览中的水色直接判断网页水体质量。本轮未发布线上更新。

模型统计与保留项摘要见 `model-audit-v8.json`；本轮文件摘要和导出检查汇总见 `export-audit-v8.json`。交付 ZIP 附带文件清单与 SHA-256，打包时检查 ZIP CRC、必要文件、GLB 长度及 Mac 文件的执行权限。
