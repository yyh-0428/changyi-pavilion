# V12：连接处、草地覆盖与水下锦鲤

本次基于上传的 V11 完整项目修复。请完整解压 `changyi-pavilion-v12.zip`，停止旧项目后运行其中的 `Start-Mac.command`。包内包含当前源码、重新构建的 `dist`、测试和本次离线预览。

## 结构接点

| 位置 | 原因 | 本次修复 |
| --- | --- | --- |
| 五面栏杆接木柱 | 横枋及压顶从柱心退让约 22 厘米，而柱半径约 17 厘米，留下透空 | 两端退让改为约 13.8 厘米，横枋及压顶伸入柱身 |
| 花格四端 | 花格宽高小于两根立棂与上下横枋之间的实际开口 | 扩展到接头内部，立棂同步接入横枋 |
| 花格交叉 | 三段分别切割的构件之间留有细缝 | 将交叉轮廓作为一个闭合实体挤出，消除内部断口 |
| 六角坐板转角 | 直切座板在转角外侧形成楔形空洞 | 两端按共同径向接面收口，双拼面板同步处理并贴合底座 |
| 坐凳靠背与牙条 | 座板内移，靠背之间缺少联结构件；牙条与承托连接不足 | 增加 15 根靠背联结撑，调整牙条高度和横向接点 |
| 灯笼 | 吊杆与梁底、垂穗与底座之间有独立间隙 | 延伸到对应构件内部，保留原摆动及灯光跟随 |

石材铺缝、座板之间有底层承接的细缝、花格的装饰开口和入口通道仍按原设计保留。

## 草地

原随机撒草使用近似椭圆范围，无法完整覆盖不规则岸线；随机分布也可能形成局部大空白。现在使用约 9.8 厘米的均匀网格并加入位置扰动，每个可种植单元保留草丛。路径、台基、树根、石灯与门墙继续避让。

平地沿真实轮廓覆盖。接近边缘时对实际地形求交，将草根放在露出水面的坡面上，补齐原先只有绿色贴图的斜坡。水下坡面的顶点颜色渐变为湿土色；没有改变岸地和湖底的形状。

当前为 **55,848 簇、335,088 片草叶**：亭岛 6,045 簇，桥头庭园 49,803 簇，其中 2,683 簇覆盖边缘带。草地保留分块实例化和原有风动方式。

## 水下锦鲤

- 合并背部 UV 接缝两侧的法线，避免随角度出现亮暗裂线。
- 嘴部使用实际开口和凹入腔体，收细口沿。
- 将腹鳍根部放入鱼体，缩小胸鳍与腹鳍的外展轮廓。
- 实体鱼皮和鳍膜分开渲染，鳍膜从根部到边缘逐渐透光，保留鳍条细节。
- 降低水下表面光泽，增加背腹色差和入水光照衰减；焦散主要作用于朝上的表面。

鱼鳍使用透明混合，因此近、远两档最多共四次绘制，原来最多两次。桌面 120 条、手机 96 条及游动、避让、工作线程与包围体规则没有改变。
