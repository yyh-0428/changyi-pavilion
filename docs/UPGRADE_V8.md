# 第八轮：补齐细作与整体复查

本轮接续工作区保留的 V7 项目，补齐上轮仓促交付的细节，并重新检查源码、构建、模型和贴图。V7 说明保存在 `docs/UPGRADE_V7.md`。

## 月洞门

- 保留 44 块实体青砖门圈、双面砖缝、内退灰缝、细倒角、20 块错缝墙裙砖及原瓦顶。
- 修正墙裙顶部、墙顶与倒角的贴图投影，避免顶部纹理挤成线。
- 修正夕照和月夜的阴影相机范围。此前夕照下月洞门落在原阴影范围之外；现在桥、亭和月洞门均在范围内，沿用原阴影分辨率。
- 增加“月洞寻幽”近景，可直接查看门圈、洞内砖面和两侧盆景。

## 植物与茶席

- 盆景补齐 54 段细枝及 162 片叶子；叶片通过枝梢连接，增加主叶脉与侧叶脉的颜色、法线细节。
- 竹叶的生长点随弯曲竹枝定位，保留五根竹秆、竹节及疏密变化。
- 16 朵鸢尾使用三片直立、三片下垂的弯曲花瓣，补充喉部颜色和起伏边缘。
- 茶汤从盆土材质中分离，使用低粗糙度、琥珀色的独立水面材质。
- 壶嘴改为沿曲线渐细的中空陶瓷结构，有内壁和口沿厚度；开口与壶嘴末端方向一致。
- 增加“一盏清茗”近景及相应缩放距离，短屏幕上的视角菜单可滚动。

## 文件与检查

V7 的源代码、材质源图、构建和轻量模型在工作区仍可读取；旧 ZIP 与月洞门预览的本地副本未找到，兼容版 GLB 的文件长度不完整。本轮从保留的源码重新生成 V8 构建、两种 GLB、五张预览与交付压缩包。这里记录的是本地文件检查结果，不代表远端旧版本已丢失。

- 自动化测试：36 项通过，包含 Mac 启动器逻辑、网格结构、导出快照和本轮几何修复。
- 生产构建：通过；保留 Three.js 主包大于 500 kB 的构建提示。
- 两种 GLB：格式校验均为 0 错误、0 警告，均成功重新导入。
- 两种 GLB 各有 32 张内嵌图片，逐张解码并检查实际像素，避免“文件有效但贴图为空”的情况。
- 轻量版与兼容版对照：153 组实例抽样的位置与颜色一致，6 片完整轻纱几何一致。
- 草地、原桃树和屋顶瓦片与 V7 的几何、实例位置及颜色哈希完全一致。
- 完成整体、月洞门正反面、茶席和鸢尾的离线渲染检查。完整范围与局限见 `docs/REVIEW_V8.md`。

## 使用

解压后双击 `Start-Mac.command`，或使用 README 中的 npm 命令。包内包含更新的源码、完整素材、`dist`、轻量 GLB、检查记录和五张预览。约 146 MiB 的兼容 GLB 已重新生成并验证，按需运行 `npm run export:model -- --compatible` 可在本地获得，未放入交付 ZIP。

原在线网站未发布更新。离线 GLB 水面为静态近似；实时倒影、折射、天空、雾和色调映射以网页运行效果为准。下一轮建议见 `docs/NEXT_UPGRADES.md`。
