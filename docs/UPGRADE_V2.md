# 长衣亭模型升级记录

对照版本：`f4d5d45`（公开仓库下载版本）。检查日期：2026-09-07。

这次升级保留原创六角重檐亭、桥头庭园、诗文和移动端界面。精度指几何连接、边界、法线、构件轮廓和生成一致性；项目没有实测图纸，不能将本次修改视为历史建筑测绘或结构安全校核。尺寸按场景约定表达。

## 发现的问题与修改

| 原有不足 | 本次处理 |
| --- | --- |
| 铺地缝线按圆形截面计算，部分纵缝超出六角边界，缺少真实的裁边铺石 | 用六个半平面裁切 77 块错缝石板，缝隙露出深色基层 |
| 柱础由两个简单圆柱拼接，柱身只有线性锥度，斗拱以直方块为主 | 增加连续柱础轮廓、微鼓收分柱身、曲线拱臂与坐斗，保持柱位和高度 |
| 屋面基层仅有朝下的单层面，近看缺少厚度与封边 | 分开构造向上的基层、向下的望板和四周封边，厚度 0.055 场景单位；瓦当跟随真实檐口切线 |
| 单瓦纵向的多段划分落在同一直线上，消耗面数；曲面与切边混用平滑法线 | 保留每片实体瓦及搭接，简化无效分段，拆开切边法线，实体板瓦使用正面渲染 |
| 桥下支撑为随坡度旋转的长方体，拼缝存在楔形重叠 | 按原有拱线建立法向截面，形成连续曲面的楔形券石，保留桥面和桥台位置 |
| 枝干接缝两端使用不周期的扰动，坐标和法线不一致 | 改为周期截面扰动并平均缝线法线；按枝径分配截面边数 |
| 叶片和草叶存在冗余分段，花瓣是压扁球体 | 叶片改为真正尖端与中脊，草叶保留六叶一簇并收束尖端，桃花使用五片有杯状弯曲与色阶的花瓣 |
| 静态合批把索引网格全部展开，整座庭园也过度合并 | 保留索引，在亭阁、庭园与各桃树范围内合批，保留阴影标记和动画父节点 |
| 灯笼内零件仍独立提交；轻纱每帧上传顶点却未更新法线 | 灯笼内部合批；轻纱通过着色器变形并修正法线，补齐动画包围范围，光源跟随悬灯支点 |
| 随机种子未在重复构建时重置，匾额依赖系统字体 | 每次构建重置种子；复用原 GLB 内嵌匾额 PNG，保留原始字形与纹理方向 |
| 渲染统计被水面内部两次绘制重置，初始包包含导出器 | 改为完整帧累计统计；点击模型导出时再加载 GLTFExporter；截图前主动绘制，关闭持续保留画布缓冲 |

## 资源对照

| 指标 | 下载版本 | 升级版本 | 变化 |
| --- | ---: | ---: | ---: |

瓦片 9,526 片（含月洞门 76 片），枝干 1,044 段，桃叶 4,752 片，花朵 2,210 朵，草丛 57,601 簇、草叶 345,606 片均保留。总实例数仍为 76,223；整体边界尺寸仍为约 27.856 × 9.490 × 42.341 场景单位。

缓冲计数包括 position、normal、uv、颜色、索引和实例矩阵/颜色；不包括纹理、帧缓冲、浏览器堆内存。三角面是全模型的几何计数，不是某一帧的 GPU 提交量。网格对象数也不等于实际 draw calls：视锥裁剪、阴影、水面反射与折射都会影响后者。不可将上述下降百分比当作 FPS 提升百分比。

网页的 `window.__pavilion.stats()` 继续提供调试统计，并新增 `geometryMetrics`；`triangles` 与 `calls` 现在明确累计整帧，因此不能直接与旧版本被内部绘制重置后的数值比较。

以下文件与下载版本一致：`src/style.css`、`index.html`、`src/lake.js`、`vite.config.js`、原 GitHub Pages 工作流。

手机断点、五个视角的位置与目标点、手机全景取景、1.65 倍近景退距、垂直偏移、手势设置、像素比上限 1.6、1024 阴影尺寸、原水面贴图尺寸及更新频率均保留。界面和页面结构没有重做。共享模型几何和渲染内部有上述修改，仍需要实机回归确认最终观感与耗电。

## 已完成验证

- `npm test`：9 项通过，覆盖几何数值与索引、瓦片封闭与面朝向、花叶非退化、枝干接缝、六角裁边、屋面双侧射线与厚度、资源预算、重复生成一致性、轻纱与灯光更新。
- `npm run export:model`：重新生成仓库中的 `changyi-pavilion.glb`。
- `npm run verify:export`：用 Three.js GLTFLoader 重新导入实际文件，核对二进制头、全部六张内嵌图片、74,013 个带实例颜色的构件、总实例与三角面数量和模型边界。
- Vite 生产构建通过；Three.js 主包仍有超过 500 kB 的常规体积提示。原运行依赖版本与 GitHub Pages 子路径配置保留，新增 Canvas 仅为离线导出/校验开发依赖。
- 静态资源引用与移动端关键设置进行了源代码对照。

本环境实时预览服务不可用，因此没有完成浏览器视觉验收、PNG 下载实测、WebGL 着色器实际编译或 iOS/Android 真机 FPS/内存/耗电测试。已通过的检查不能替代这些结果。当前也没有推送仓库或更新线上网页。

## 运行与交付

```sh
npm ci
npm run dev
npm test
npm run export:model
npm run verify:export
npm run build
```

源码包包含修改后的完整项目、重新导出的 GLB、此说明及 `dist` 构建目录。原项目以 `/changyi-pavilion/` 为发布子路径，建议通过开发服务器或按原 GitHub Pages 流程查看，不要直接双击 HTML。

GLB 保留实例化以控制体积。它包含静态建筑、植物、桥与庭园；水、天空、运行时灯光、风动和自定义着色器效果由网页提供。无扩展支持的查看器可能无法完整还原实例、颜色或材质。
