# 第五轮升级：写实材质与室外光照

基于第四轮 `8c0454e`，本轮分支 `upgrade/realistic-materials`。Mac 启动与上一轮帘幕改造记录保存在 [docs/UPGRADE_V4.md](./docs/UPGRADE_V4.md)。

## 看得见的变化

- 木构、自然树皮、石材和青瓦采用独立的程序材质。颜色变化、物理高度和粗糙度分别生成，形成木纹细孔、树皮裂隙与横向皮孔、石材颗粒、瓦面的烧制色差和浅孔隙。石、木、瓦保持非金属表面；青瓦使用标准材质，取消额外清漆层。
- 轻纱增加细织纹与轻微法线起伏，保留原有透明度、收束轮廓、单次双面绘制与风动。灯笼加入纸纤维、骨架附近和上下收口的明暗变化，颜色与发光共用一张纹理。
- 对 87 个较大的木石方形构件增加内收倒角：木构约 3 毫米、石构约 6 毫米。倒角保持原构件外包尺寸，保留原有接缝与净空。新增 2,784 个三角面，继续参与原有合批。
- 木梁和木柱的纹理按构件尺度铺设，端面保留完整二维映射；大石台的侧面、顶面与石栏杆也调整了纹理比例，避免统一拉伸一张纹理。
- 夕照的天空太阳与方向光使用同一个方向，环境反射改由室外天空和地面生成。环境贴图只在初始化时烘焙一次。月夜主光与月亮方向一致，降低全局照度，使暖色灯笼与冷色月光区分更清楚。光照为艺术场景的相对强度，未标定现实照度。

## GLB 一致性

网页和命令行共用 `src/lighting.js` 的夕照、月夜预设，并在场景元数据中记录背景、雾、环境强度和曝光。CLI 导出也同步灯笼的发光强度。

颜色纹理使用 sRGB；法线与粗糙度采用非颜色数据。粗糙度按标准 glTF 的绿色通道保存；同一种表面的纹理由不同构件共享，导出时复用已打包的图像。帘幕纹理比例通过 `KHR_texture_transform` 保存。两种 GLB 均内嵌 21 张图像，使用 8 张标准法线纹理，保留 6 盏点光、2 盏方向光和当前相机。

导出水面调整为非金属、折射率 1.333 的静态 PBR 近似。网页的实时反射、折射和水面算法保持原样。GLB 本身不能复现网页的完整天空、雾、环境光、色调映射和动态倒影；导入后选择“当前视角”相机，并由查看器提供合适的环境光。不能承诺在不同软件中逐像素一致。

新表面纹理使用 256² 像素，纱与纸使用 128² 像素，在增加材质区分的同时降低了模型纹理总像素量。几何缓冲与上述纹理估算合计下降约 2.07%。此统计不含水面、环境贴图、阴影、帧缓冲、浏览器堆和驱动开销，也不能换算为 FPS。部分材质增加了粗糙度采样，青瓦则减少了清漆着色开销；真实设备上的性能仍需实测。

9,526 片瓦、1,044 段枝干、4,752 片桃叶、2,210 朵花和 57,601 簇草保持原数量。66,797 个实例的几何、矩阵与颜色数据对照第四轮的 SHA-256 完全一致，纹理生成不再影响庭园随机序列。模型外包尺寸保持约 27.856 × 9.490 × 42.341 场景单位。

手机布局、相机、视角切换、手势、像素比、阴影分辨率、水面渲染设置、Mac 启停脚本和依赖锁文件均保留。保护文件及相机代码片段的校验值见 [docs/model-audit.json](./docs/model-audit.json)。

材质参数遵循 [Three.js 标准材质文档](https://threejs.org/docs/pages/MeshStandardMaterial.html) 和 [色彩管理说明](https://threejs.org/manual/en/color-management.html)，实现针对项目锁定的 Three.js 0.180.0。

## 使用与交付

下载 `changyi-pavilion-v5-realism.zip`，解压后在 Mac 双击 `Start-Mac.command`。启动方法与 [MAC_QUICKSTART.md](./MAC_QUICKSTART.md) 一致。

压缩包包含源码、Mac 启停脚本、轻量 GLB、生产构建 `dist` 和验证记录，保存脚本执行权限；不含依赖目录和临时会话文件。兼容 GLB 单独提供，也可运行 `npm run export:model -- --compatible` 生成。

本轮仅完成本地修改与打包，未推送 GitHub，线上预览尚未更新。
