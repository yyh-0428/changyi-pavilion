# 长衣亭

为张依婷创作的原创六角重檐亭阁，以及可交互的网页展示。诗文保留全部八句，网页中不显示诗题。

**当前版本：V13 屋瓦承托与草地显示修复。**

屋瓦搭接及垂脊下方补齐承托；草叶按绘制像素平滑过渡到地表，底色与局部细节分别采样。三维加载失败仍可阅读完整诗笺；图片保存含姓名与所选诗句。下方 V12 及更早记录保留为历史说明。

完整解压本包，先停止旧项目，再运行新目录中的 `Start-Mac.command`。包内 `dist` 已重新构建；首页和“观鲤 / 观亭”入口沿用原布局。

## 历史修复（V12）

- 五面栏杆的横枋和压顶伸入木柱；花格端部接入横枋与立棂，交叉处改成连续实体。
- 六角转角坐板按共同接面收口，面板贴合座板；补上靠背联结撑，调整牙条与腿架的连接。
- 补齐灯笼吊杆接梁、垂穗接底座处的断点。
- 草地沿实际不规则地表铺设，覆盖露出水面的岸边斜坡。水下坡面改为湿土色，避免出现整片绿色蒙皮。
- 锦鲤修复背部法线接缝，嘴部改为凹入开口，收小胸鳍和腹鳍，并加入渐变透光、背腹色差和随水深变化的光照衰减。

原反射边缘修正、浅滩几何、水面分辨率、鱼数、游动模拟和 V11 渲染分区保留。详情和验证范围见 [V12 修复记录](./docs/DETAIL_FIX_V12.md)。本包没有发布到原线上网页。

## 历史升级（V9—V11）

V11 提前排除水面裁切后完全不可见的整批几何；水面上下交界、灯笼和轻纱仍参与原通道，风动草丛使用覆盖全部摆幅的保守范围。三个画面共用每帧一次的场景矩阵更新，并在加载阶段异步预编译主画面与 HDR 水面材质，减少首次绘制时的编译停顿。

默认夕照全景下，电脑每帧提交三角面由 8,728,904 降至 6,641,374，手机由 8,469,944 降至 6,471,730，约减少 **24%**。这是按 Three.js 实际虚拟相机、视锥及绘制规则计算的提交量，包含主画面、倒影、折射和阴影；不是 GPU 耗时或真实设备帧率。主画面和阴影的绘制对象保持一致，当时的模型为 2,549,612 个三角面。算法、数据对照与限制见 [V11 性能说明](./docs/PERFORMANCE_V11.md)。

V10 给五面坐凳补齐 20 根落地榫腿、10 根承托和配套牙条、横枨；五面栏杆增加柔和倒角的压顶，匾框使用 45 度接角与细倒棱，额枋增加细木线脚，曲线雀替的木纹顺构件延伸。新增构件复用原材质和合批流程。

手机原本使用更远的全景机位，原指数雾会随镜头距离增强，让亭子显得发白。现在雾从主体后方的远岸开始：保留远景层次，近处亭子与鱼群保持清晰，不依靠降低分辨率调整画面。说明见 [V10 更新记录](./docs/PAVILION_V10.md)。

V9.2 将鱼材质中的 GLSL ES 保留字 `patch` 改为 `patchNoise`，并更新材质程序缓存标识。已先复现用户日志中的相同编译错误，再确认修复后的 4 个完整着色器程序按原始 `#version 300 es` 编译、链接成功。检查脚本不再改成桌面 GLSL，因此可捕捉此次浏览器错误。说明与结果见 [着色器修复记录](./docs/SHADER_FIX_V9_2.md)。

V9.1 修复首帧完全依赖 Worker 的启动隐患：先在本地生成完整鱼群，后台线程加载失败、消息解码失败或超过 2 秒未响应时自动接管游动。水下鱼体使用独立渲染层，只由折射相机绘制，不再临时隐藏整个鱼群。新增 3 项回归，连同原有关键测试共 14 项通过。详见 [显示修复说明](./docs/FISH_VISIBILITY_V9_1.md)。

V9 在 V8 场景中加入自由游动的锦鲤：桌面 120 条，手机 96 条。暖白、朱红与香槟金三组花色带有个体斑纹、体长和胖瘦变化，鱼体包含鳞片细纹、鳃盖、口须、双眼与成对鱼鳍。

鱼群使用独立线程、固定步长模拟和空间网格；提前避让、保守包围体与非穿透约束共同处理鱼之间及岸边的间距。尾摆、胸鳍、倾斜和转向与速度联动，并通过原水面的折射与深度衰减显示。V9 的近远景共用两档模型与一个材质。V12 将实体鱼皮与透明鳍膜分开，最多四次鱼群绘制；鱼数、水面分辨率和全局像素比沿用原设置。

打开先看原庭园全景，顶部点击 **“观鲤”** 进入鱼群近景。包内保留 V9 的 8 秒游动专项预览和封面图。实现与性能边界见 [鱼群架构说明](./docs/FISH_ARCHITECTURE.md)，本轮修改见 [UPGRADE_NOTES.md](./UPGRADE_NOTES.md)。

## Mac 快捷启动

解压完整项目后，双击 **Start-Mac.command**；首次自动安装依赖并打开浏览器。结束时按 **Control+C** 或双击 **Stop-Mac.command**。缺少 Node.js 时会打开官方下载页，建议安装 24 LTS 后重试。详见 [MAC_QUICKSTART.md](./MAC_QUICKSTART.md)。

启动脚本支持中文和空格路径、端口占用后自动换端口、重复启动复用服务，以及按项目停止；保留原有手机界面和操作方式。

## 运行

```sh
npm install
npm run dev -- --host 127.0.0.1
```

生产构建：`npm run build`。发布 `dist` 目录即可。

模型校验：`npm test`。需要静态建筑 GLB 时按需生成：`npm run export:model`，再运行 `npm run verify:export` 验证重新导入。离线生成使用开发依赖 `@napi-rs/canvas`，不会进入网页代码。

历轮模型升级、Mac 启动方式、性能口径和验证范围见 [UPGRADE_NOTES.md](./UPGRADE_NOTES.md)。

## 场景

- Three.js PBR 木构、青瓦、石台、栏杆、斗拱、题字、轻纱和灯笼。重檐屋顶采用 9,450 片随曲面收分的实体板瓦/筒瓦，另有月洞门 76 片盖瓦，保留搭接厚度、瓦当和材质差异。
- 增加环梁、斜撑、三层藻井梁架、檩条与椽子。三株桃树包含 1,044 段渐细枝干、4,752 片有叶脉和卷曲的桃叶，以及逐枝分布的五瓣花。
- 屋面补齐 0.055 场景单位厚的望板、檐下表面和封边，瓦当方向跟随檐口曲率；柱础与柱身具有连续收分轮廓，斗拱增加曲线承托与坐斗。地坪改为 77 块沿六角边界裁切的错缝铺石。
- 桥头连接实体岸地、连续曲折石径、月洞门与石灯，亭内设双人茶席。桥下增加拱形承托石和两端桥台。
- 桥下两侧券石按拱线法向切分；桥板和园路按曲线裁切，桥尾采用统一断面接缝，月洞门开口避开路面与路缘。
- 草地采用世界坐标地表纹理与 55,848 簇实体草丛，共 335,088 片弯曲草叶，覆盖岛上和桥头庭园。草丛按空间分块实例化，具备高度/颜色变化及轻微风动，避让石径、台基、门墙、树根和石灯。
- 水面采用 Three.js Reflector/Refractor 的独立反射与折射视图，按窗口比例生成最高 2048 像素的 HDR 反射图。深度纹理重建湖底位置，并按光路长度进行 Beer-Lambert 吸收和菲涅耳混合；两个几何波与三层流动法线形成水面细节。
- 配套渐深的浅滩和湖底，近岸透射、深水吸收与灯光倒影使用同一套水体材质。反射相机处理了偏移构图，避免倒影错位和画面边缘拉伸。
- 檐角收头和屋顶宝顶改用低矮的青灰陶质构件，去除外露的金黄色翘角。顶部、底部界面使用低不透明度玻璃底色，菜单和诗笺保留适当对比度。
- 夕照与月夜、八个观景视角、自动环绕、诗笺、图片导出和 GLB 场景快照导出。细节视角隐藏大标题，避免遮挡模型。
- 建筑与植物使用自建几何、程序 PBR 数据和随项目提供的三张生成材质源图；水面法线采用 Three.js 官方示例贴图。所有资源随包提供，运行时无需外部素材或图片服务。
- 桌面与手机分别限制像素比、反射贴图和阴影贴图尺寸。
- 保留原有瓦片与植被数量，另外增加实体脊瓦和亭子构件。静态构件采用索引合批并保留逐件颜色，灯笼保留可动画的合批支点，轻纱以 GPU 变形并修正法线，收束轮廓和椭圆系环同步摆动。完整静态模型约 253 万三角面，几何与实例缓冲约 20.04 MiB，可绘制网格 110 个；远景草块按屏幕像素尺度剔除。
- 匾额贴图直接复用原 GLB 内嵌字样，不依赖终端是否安装相同中文字体；草地、树木和瓦片在重复生成与离线导出时保持相同分布。

模型是原创艺术设计，不是特定历史建筑的测绘复原；水面是适合实时网页的光学近似，并非离线光线追踪或完整流体模拟。

## 文件

本轮按要求不生成、不打包 GLB。鱼群直接由网页源码构建和驱动，启动时不读取 GLB。原有建筑导出功能仍可按需使用；它不包含运行时鱼群。

网页与命令行共用原建筑场景快照和导出流程，复制当前草叶、轻纱、灯笼姿态及材质，保留地形、湖底、两盏方向光、六盏点光和当前相机。凹凸细节使用共享的标准法线贴图，导出时补齐切线，不再依赖 `EXT_materials_bump`。

| 文件 / 菜单 | 用途 |
| --- | --- |
| `changyi-pavilion.glb` / 轻量场景 | 本包不附带，可按需导出；保留 `EXT_mesh_gpu_instancing`，需要查看器支持该扩展及实例颜色 |
| `changyi-pavilion-compatible.glb` / 兼容场景 | 本地按需生成；实例展开为普通索引网格，颜色写入标准 `COLOR_0`，适合建模软件导入 |

兼容文件仅在执行 `npm run export:model -- --compatible` 后生成，因超过 GitHub 单文件大小限制不纳入 Git；验证使用 `npm run verify:export -- --compatible`。`npm run export:model -- --model-only` 可生成不带场景环境的轻量建筑庭园版本。

**导入后选择“当前视角”相机**。完整地形尺度大于亭阁，查看器自动框选全场景时，建筑会显得较小。水面保留导出时刻的两层几何波，材质是静态 PBR 近似；实时倒影、折射、深度吸收、程序天空、雾、环境照明、ACES 色调映射及相机偏移不属于可原样移植的通用 GLB 效果。其他查看器需要自己的环境光设置，无法承诺逐像素一致。月夜下载保留当时可见的月亮与星点。

兼容导出的体积和临时内存开销只发生在点击导出时；日常网页继续使用实例化，不加载这个大文件。低内存手机优先使用轻量场景。新增近景沿用原有手机相机适配与手势；视角菜单增加高度限制和滚动，以容纳八个视角。

`previews/fish-swimming-v9.mp4` 是 8 秒鱼群专项预览，使用实际鱼体、模拟状态和水面着色器在原生渲染器中生成；省略建筑、天空与全场景环境，并非浏览器录屏或帧率证明。此前的五张 V8 模型预览作为历史对照保留。
