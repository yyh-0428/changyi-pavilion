# 长衣亭

为张依婷创作的原创六角重檐亭阁，以及可交互的网页展示。诗文保留全部八句，网页中不显示诗题。

**在线预览**：<https://yyh-0428.github.io/changyi-pavilion/>（推送到 `main` 后由 GitHub Actions 自动构建部署）

## 运行

```sh
npm install
npm run dev -- --host 127.0.0.1
```

生产构建：`npm run build`。发布 `dist` 目录即可。

## 场景

- Three.js PBR 木构、青瓦、石台、栏杆、斗拱、题字、轻纱和灯笼。重檐屋顶采用 9,450 片独立实体板瓦/筒瓦，另有月洞门 76 片盖瓦，保留搭接厚度、瓦当和材质差异。
- 增加环梁、斜撑、三层藻井梁架、檩条与椽子。三株桃树包含 1,044 段渐细枝干、4,752 片有叶脉和卷曲的桃叶，以及逐枝分布的五瓣花。
- 桥头连接实体岸地、连续曲折石径、月洞门与石灯，亭内设双人茶席。桥下增加拱形承托石和两端桥台。
- 草地采用世界坐标地表纹理与 57,601 簇实体草丛，共 345,606 片弯曲草叶，覆盖岛上和桥头庭园。草丛按空间分块实例化，具备高度/颜色变化及轻微风动，避让石径、台基、门墙、树根和石灯。
- 水面采用 Three.js Reflector/Refractor 的独立反射与折射视图，按窗口比例生成最高 2048 像素的 HDR 反射图。深度纹理重建湖底位置，并按光路长度进行 Beer-Lambert 吸收和菲涅耳混合；两个几何波与三层流动法线形成水面细节。
- 配套渐深的浅滩和湖底，近岸透射、深水吸收与灯光倒影使用同一套水体材质。反射相机处理了偏移构图，避免倒影错位和画面边缘拉伸。
- 檐角收头和屋顶宝顶改用低矮的青灰陶质构件，去除外露的金黄色翘角。顶部、底部界面使用低不透明度玻璃底色，菜单和诗笺保留适当对比度。
- 夕照与月夜、五个观景视角、自动环绕、诗笺、图片导出和 GLB 模型导出。细节视角隐藏大标题，避免遮挡模型。
- 建筑与植物使用自建几何和程序纹理；水面法线采用 Three.js 官方示例贴图，已下载到本地，运行时无需外部素材或图片服务。
- 桌面与手机分别限制像素比、反射贴图和阴影贴图尺寸。

模型是原创艺术设计，不是特定历史建筑的测绘复原；水面是适合实时网页的光学近似，并非离线光线追踪或完整流体模拟。

## 文件

`changyi-pavilion.glb` 是可导入 Blender 等软件的模型，包含建筑、植物和桥头庭园，使用 `EXT_mesh_gpu_instancing` 保留大量重复构件。网页中的水、天空、照明和动画由 Three.js 运行时提供，不包含在静态 GLB 中。

网页实拍截图（`preview-*.png`）与画布导出图（`changyi-render.png`）体积较大，未纳入本仓库，仅保留在本地。
